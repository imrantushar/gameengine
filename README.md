# GameEngine

Gamification for WordPress — points, achievements, ranks and leaderboards.

Public repository: <https://github.com/imrantushar/gameengine>
Licensed GPL-2.0-or-later. Everything in this plugin is free; nothing is gated
behind a key, a trial, a quota or a time limit.

## Where the source is

The only generated files in this plugin are in `assets/build/`. Each one is
named after the source file it is built from, and the uncompiled source for all
of them ships inside the plugin:

| Generated file                  | Built from                                                |
| ------------------------------- | --------------------------------------------------------- |
| `assets/build/backend.js`       | `src/backend.js` — the admin app                           |
| `assets/build/frontend.js`      | `src/frontend.js` — the frontend script                    |
| `assets/build/setup.js`         | `src/setup.js` — the setup wizard                          |
| `assets/build/backend.css`      | `assets/scss/backend.scss`                                 |
| `assets/build/frontend.css`     | `assets/scss/frontend.scss`                                |
| `assets/build/setup.css`        | `assets/scss/setup.scss`                                   |
| `assets/build/*-rtl.css`        | the same Sass, flipped by the build                        |
| `assets/build/*.asset.php`      | generated by the build: dependencies and a content hash    |

Those three entry points pull in the rest of `src/`, which is the complete
uncompiled React source: `components/`, `containers/`, `redux/`, `hooks/`,
`utils/` and `frontend/`. Nothing is minified, obfuscated or downloaded at
build time from anywhere but npm.

Every generated file also carries a comment at the top naming its own source
file and the command that rebuilds it.

## Building

Requires Node.js 18 or newer.

```sh
npm install
npm run build     # production build, writes assets/build/
npm run start     # the same build in watch mode
npm run lint:js   # ESLint
```

The build is [@wordpress/scripts](https://www.npmjs.com/package/@wordpress/scripts)
(webpack + Babel + Sass) with Tailwind CSS and PostCSS. The configuration ships
too: `webpack.config.js`, `tailwind.config.js`, `postcss.config.js`,
`jsconfig.json`, and `package.json` with `package-lock.json` pinning an exact,
reproducible dependency tree.

PHP dependencies are declared in `composer.json` and pinned in `composer.lock`:

```sh
composer install
```

## Layout

```
gameengine.php      plugin bootstrap
includes/           PHP: REST controllers, triggers, integrations, add-ons
templates/          PHP templates for the shortcodes
src/                uncompiled React source (admin app, setup wizard, frontend)
assets/scss/        uncompiled Sass
assets/build/       generated — do not edit, run `npm run build`
assets/images/      static images
languages/          translation template
```

## External services

None. The plugin makes no HTTP requests to any third party, loads no remote
fonts, scripts, stylesheets or images, and sends no data off the site it runs
on. It works identically with no internet connection.
