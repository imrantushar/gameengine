== Description ==

**Gamify** is a complete gamification plugin for WordPress designed to boost user engagement and build a loyal community. It allows you to create a fun, interactive experience by rewarding users with points, achievements, and ranks for participating on your site.

Whether you run a blog, an e-learning platform, a forum, or an e-commerce store, Gamify helps you motivate your users by turning site interactions into a rewarding game.

**Key Features:**

*   **Powerful Points System:** Award or deduct points for various activities like registration, daily visits, post publishing, commenting, and more.
*   **Customizable Point Types:** Create multiple types of points like Coins, Gems, or XP to build a rich virtual economy.
*   **Achievements & Badges:** Define achievements that users can unlock by completing specific tasks or reaching milestones. Reward them with beautiful badges.
*   **Rank System:** Motivate users to climb the ladder! Create ranks (e.g., Bronze, Silver, Gold) that users can earn by accumulating points.
*   **Automated Trigger Engine:** Set up powerful, automated triggers that fire based on user actions, manual input, or a schedule (cron jobs).
*   **Detailed Activity Logs:** Keep track of every point awarded and every achievement unlocked with a comprehensive logging system.
*   **Modern Admin Dashboard:** Manage your entire gamification system from a beautiful and fast React-powered admin panel.
*   **Developer Friendly:** Built with a modern, extensible architecture, making it easy for developers to add custom features and integrations.

Gamify is the ultimate tool to make your website more engaging, interactive, and fun!

== Installation ==

1.  Upload the `gamify` folder to the `/wp-content/plugins/` directory.
2.  Activate the plugin through the 'Plugins' menu in WordPress.
3.  Go to the "Gamify" menu in your WordPress admin dashboard to start configuring your gamification system.

That's it! You're ready to gamify your website.

== Frequently Asked Questions ==

= What kind of activities can I award points for? =

You can award points for almost any action in WordPress! Out of the box, you can set up triggers for user registration, daily logins, publishing posts, leaving comments, and more. The system is designed to be extensible, so developers can easily add new triggers.

= Can I have more than one type of point? =

Yes! Gamify supports multiple point types. You can create "Coins", "Gems", "XP", or any other currency you can imagine to create a rich rewards system.

= Is it possible to integrate Gamify with other plugins like WooCommerce or LearnDash? =

While the initial version focuses on core WordPress interactions, the plugin is built with extensibility in mind. Future versions will include official integrations, and developers can use the provided hooks and functions to build their own integrations.
